# MY WORLD на Android — первый запуск

Этот способ запускает MY WORLD прямо на телефоне. Нужен Termux и Node.js. Cloudflare, API-токен и внешняя база данных не нужны.

## Один раз подготовить телефон

1. Установи Termux из [официальной страницы F-Droid](https://f-droid.org/packages/com.termux/). Не смешивай APK Termux из разных источников: подписи сборок могут отличаться.
2. Открой Termux и выполни:

```bash
termux-setup-storage
pkg update
pkg install nodejs-lts unzip -y
```

3. Скачай `MY_WORLD-local-build.zip` и сохрани его в папку «Загрузки» телефона.
4. В Termux выполни:

```bash
mkdir -p ~/my-world
unzip ~/storage/downloads/MY_WORLD-local-build.zip -d ~/my-world
cd ~/my-world
bash start-android.sh
```

## Открыть сайт

Оставь Termux запущенным и открой в обычном браузере телефона:

`http://127.0.0.1:8787`

Пароль появится в окне Termux при первом запуске. Он сохранится в `~/my-world/.my-world-data/app-password.txt`. Мир сохраняется автоматически в той же папке.

Чтобы остановить сервер, вернись в Termux и нажми `CTRL+C`. Для следующего запуска достаточно открыть Termux и выполнить:

```bash
cd ~/my-world
bash start-android.sh
```

## Важно для фоновой симуляции

Фоновая жизнь продвигается, пока Termux и Node.js продолжают работать. Не закрывай Termux принудительно. В настройках Android отключи оптимизацию батареи для Termux или разреши ему неограниченную фоновую работу. Если Android остановит процесс или телефон выключится, мир будет ждать следующего запуска; пропущенные часы автоматически не проигрываются.

## Что работает без языковой модели

Потребности, эмоциональное состояние, мотивы, память, привычки, обучение и бытовые действия работают локально. Для свободных диалогов и придуманных в конкретной ситуации нестандартных занятий потребуется локальная OpenAI-совместимая языковая модель на компьютере/сервере либо отдельно настроенный провайдер. Сам когнитивный движок от неё не зависит.
