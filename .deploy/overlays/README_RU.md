# MY WORLD — цифровая психика и локальный прототип

MY WORLD развивается в сторону платформы отдельных историй и миров, где пользователь сможет создавать персонажей и запускать собственные сценарии. **Текущая сборка — рабочий прототип одного мира**, а не завершённый много-мировой конструктор. Стартовые персонажи демонстрационного мира — Джейкоб и Пенни.

## Запуск на своём компьютере без Cloudflare

Требуется Node.js 22 или новее. Для этого режима не нужно создавать аккаунт Cloudflare, API-токен, D1 или устанавливать npm-пакеты.

1. Распакуй архив проекта.
2. Открой терминал в папке `MY_WORLD_0_5`.
3. Выполни `npm run start:local`.
4. Открой `http://127.0.0.1:8787`.

При первом запуске пароль входа появится в терминале и сохранится в `.my-world-data/app-password.txt`. Состояние мира хранится в `.my-world-data/local-db.json`. Не публикуй эту папку и регулярно делай резервную копию.

По умолчанию сервер слушает только это устройство. Чтобы открыть доступ другим устройствам в домашней сети, можно задать `MY_WORLD_HOST=0.0.0.0`; не выставляй такой сервер напрямую в интернет без HTTPS и отдельной защиты.

## Цифровая психика

Внутренняя модель персонажа включает потребности, эмоциональные сигналы, внимание, мотивы, рабочую и долговременную память, убеждения, привычки, навыки и цели. Бытовые решения исполняются локальным кодом. Если готового действия не хватает, подключённая языковая модель может предложить новое действие; движок проверяет место, цель и длительность, применяет результат и сохраняет опыт.

Это вычислимая модель поведения, а не утверждение о настоящем сознании.

## Языковая модель — необязательно

Без модели работают бытовые циклы, память и состояние мира. Для свободных разговоров и придуманных в конкретном контексте новых занятий можно подключить локальную OpenAI-совместимую модель, например Ollama:

```bash
LOCAL_LLM_BASE_URL=http://127.0.0.1:11434/v1 LOCAL_LLM_MODEL=qwen3:8b npm run start:local
```

Модель должна быть предварительно запущена на этом же компьютере или сервере. Для простого поведения она не нужна. Подключение модели зависит от мощности твоего оборудования; локальный запуск не создаёт бесконечные вычислительные ресурсы.

Фоновые ходы выполняются, пока локальный сервер запущен. По умолчанию один игровой ход происходит каждый час. Изменить интервал можно переменной `MY_WORLD_TICK_MINUTES`; значение `0` отключает автоматические ходы.

## Облачная публикация — отдельный, необязательный путь

В репозитории остаётся Cloudflare deployment workflow. Он нужен только при выборе облачного размещения и требует настройки Cloudflare. Для локальной работы он не нужен.
