# MY WORLD 0.5 — облачная симуляция автономных персонажей

MY WORLD — это небольшой облачный мир с отдельными ИИ-агентами, виртуальным временем, расписаниями, потребностями, целями, памятью, асимметричными отношениями и журналом событий.

Это **симуляция поведения**, а не доказательство сознания или субъективного опыта модели.

## Что находится в проекте

- `src/core.js` — правила мира, личности, потребности, память, отношения, проверка действий.
- `src/worker.js` — Cloudflare Worker, авторизация, вызовы моделей, Cron и API.
- `public/index.html` — мобильный интерфейс.
- `public/sw.js` — офлайн-кэш оболочки приложения; API и приватные данные не кэшируются.
- `migrations/0001_init.sql` — таблицы Cloudflare D1.
- `tests/` — автоматические проверки движка, AI-адаптеров и фронтенда.
- `wrangler.jsonc` — конфигурация развёртывания.

## Что означает «автономность» в этой версии

- Cloudflare Cron запускает один цикл каждый час, даже когда телефон и страница закрыты.
- Виртуальное время идёт со скоростью один игровой час за реальный час.
- Каждый персонаж получает отдельный запрос к языковой модели и выбирает собственное действие.
- Все решения строятся по одному снимку мира; затем сервер проверяет их и применяет.
- У персонажей отдельные биографии, потребности, расписания, цели, память и мнения о других.
- Новое сообщение в разговоре показывается адресату как входящее только один раз; история остаётся доступной как контекст.
- Каждый агент видит собственные шесть последних решений: это помогает учитывать недавнее поведение, а не начинать каждый час с нуля.
- Персонажи могут не разговаривать, отказываться, продолжать дело, менять планы или сохранять дистанцию.
- Действия модели проверяются кодом. Модель не может самостоятельно добавлять несуществующие локации, мгновенно телепортировать себя, менять чужую память или выставлять отношения за пределами шкалы.
- Повторяющиеся события и рутинные решения не превращаются в бесконечный поток записей.

Для четырёх персонажей это максимум 96 отдельных агентских решений в сутки, плюс сообщения пользователя в личных чатах. При добавлении персонажей число запросов растёт линейно.

## Поддерживаемые модели

### Основная: Groq — Qwen 3.8 27B

- API: `https://api.groq.com/openai/v1/chat/completions`
- ID модели: `qwen/qwen3.8-27b`
- Groq помечает её как Preview: доступность может измениться без долгого переходного периода. При ошибке приложение автоматически пробует `openai/gpt-oss-20b` на том же Groq API, затем резервный Cloudflare Workers AI.
- Используется в instruct-режиме (`reasoning_effort: none`) с JSON Object Mode для решений.
- Её доступность и лимиты проверяются в аккаунте Groq.
- Ключ вводится только как серверный секрет `GROQ_API_KEY`, никогда не в HTML.

Создать ключ: https://console.groq.com/keys

### Второй маршрут Groq: OpenAI GPT-OSS 20B

- ID модели: `openai/gpt-oss-20b`
- Используется автоматически, если Qwen 3.8 27B недоступна или возвращает ошибку. Можно изменить через `GROQ_FALLBACK_MODEL` в `wrangler.jsonc`.

### Резервный провайдер: Cloudflare Workers AI — GPT-OSS 20B

- ID модели: `@cf/openai/gpt-oss-20b`
- Используется через binding `AI`.
- Бесплатная квота Workers AI — 10 000 нейронов в сутки. При превышении операции могут завершаться ошибкой до следующего сброса квоты.
- GPT-OSS 20B не включён в текущий список поддерживаемых Cloudflare JSON Mode моделей, поэтому сервер просит JSON в инструкции и валидирует разобранный ответ отдельно.

Справка: https://developers.cloudflare.com/workers-ai/platform/pricing/

### Переключение между провайдерами

- Если Qwen на Groq отвечает ошибкой, Worker пробует GPT-OSS 20B на Groq, а затем Cloudflare AI.
- Если Groq ограничивает запросы, Worker пробует Cloudflare AI; при временной ошибке Cloudflare может вернуться к Groq, пока не достигнут жёсткий защитный порог.
- Если Cloudflare недоступен, Worker может использовать Groq, пока не сработал внутренний защитный порог.
- При наличии обоих провайдеров приложение заранее снижает расход Groq и переключает часть нагрузки на Cloudflare.
- Если все модели недоступны три цикла подряд, мир автоматически ставится на паузу. Он не генерирует фальшивые ответы.

Groq имеет бесплатный Free plan и отдельный платный Developer plan. На странице rate limits есть переключение между планами; значения Developer plan нельзя автоматически считать лимитом Free plan. Точные значения для организации смотри в разделе Limits аккаунта: https://console.groq.com/docs/rate-limits. При 429 приложение переключает запрос на резервные маршруты.

### Почему не добавлены другие бесплатные API

- OpenRouter Free ограничен 50 запросами в сутки; четырём агентам при часовом цикле требуется до 96 решений в сутки ещё до сообщений пользователя.
- Gemini API имеет бесплатный уровень, но Google указывает, что данные бесплатного уровня могут использоваться для улучшения продуктов. Поэтому этот маршрут не включён по умолчанию для личной памяти и переписок персонажей.

## Ограничения бесплатной инфраструктуры

- Cloudflare Workers Free: до 100 000 запросов в сутки и 10 ms CPU на Cron-вызов. Сетевое ожидание AI/D1 не считается CPU, но интенсивная обработка может выйти за лимит.
- Workers AI: 10 000 нейронов в сутки без оплаты; квота сбрасывается ежедневно в 00:00 UTC.
- Cron `0 * * * *` поддерживается Cloudflare и вызывает Worker каждый час.
- D1 имеет собственные бесплатные лимиты хранения и чтения/записи; их нужно отслеживать в панели аккаунта.
- Groq предоставляет rate-limited доступ, но точные значения необходимо проверять для своего аккаунта.
- «Бесплатно» здесь означает работу в пределах доступных квот. Это не гарантия постоянного 24/7 при любой нагрузке; если квоты исчерпаны, симуляция может ждать сброса или ручного запуска.

## Запуск тестов

Нужен Node.js 20 или новее.

```bash
npm test
```

Для тестов провайдеров используются заглушки `fetch`/Workers AI. Тесты не расходуют реальные токены и не проверяют действительность аккаунта или API-ключей.

## Безопасность

Тексты профилей, наблюдения, воспоминания и сообщения персонажей отправляются выбранному внешнему ИИ-провайдеру для генерации решений. Не помещай в мир реальные пароли, адреса, медицинские данные и другие сведения, которые не хочешь передавать API-провайдерам.

- `APP_PASSWORD` и `GROQ_API_KEY` задаются только через Cloudflare Worker Secrets.
- API закрыто cookie-сессией HttpOnly/Secure/SameSite=Strict.
- На логин действует ограничение попыток.
- Service worker не кэширует `/api/*`.
- Не публикуй GitHub-репозиторий с секретами, не добавляй ключи в `wrangler.jsonc` и не вставляй API key в клиентский код.

## Важные оговорки

1. Проект подготовлен к развёртыванию, но ещё не опубликован в твоём Cloudflare-аккаунте.
2. Внешние провайдеры в тестах заменены заглушками: реальные API-ключи не предоставлены и живой инференс отсюда не проверялся.
3. На реальном Android-устройстве визуальное тестирование не проводилось.
4. Персонажи A/B/C — временные заглушки, их личности ещё нужно определить. Джейкоб добавлен на основе уже заданного профиля.
5. Модель может ошибаться, выдумывать детали и нарушать стиль. Движок проверяет структуру и доступные действия, но не может гарантировать художественное качество каждой реплики.
